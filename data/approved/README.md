# 承認済み記事のみを配置するフォルダ

ここに置かれた `YYYY-MM-DD.json` だけが、その日の夜9時以降の公開候補になります。未確認ニュースは配置しないでください。

承認JSONには `status: "approved"`、配信日 `editionDate`、タイトル、5本のニュース、編集者の承認情報が必要です。5本すべてに出典（HTTPS）、2件以上の検証用URL、個別の事実確認と配慮チェックが必要です。必須条件は `publish_approved.py` を参照してください。

**収集されたニュース候補は承認されていません。** 自動収集だけでは公開されません。出典は2件あっても、それだけで正確さが保証されるわけではありません。元記事に戻り、事実・文脈・日時・結果・当事者への影響を確認してください。

このフォルダは公開GitHubリポジトリに含まれますが、デプロイするWebサイトの成果物には含めません。したがって、配信前でもGitHub上では閲覧できます。非公開の個人情報を置かないでください。
