## 国別コンテンツの編集と承認（2026-11-21）

`country-content.json` が196か国・地域の国紹介・ライセンス付き代表写真・2問クイズ・小旅行・時事トピック・編集承認状況を一元管理する唯一の編集原本です。従来の `index.html` / `world-passport.js` / `travel-stops.json` / `country-highlights.json` は互換性のための出力先です。

- 新しい国は `pending` から開始し、国・史実・文化の出典と写真の出所、クイズ、旅の文章を編集確認してから `approved` に変更します。現在の明示承認は IT / DE / US / FR / AR / JP / GB の7か国です。フランス・アルゼンチン・日本・英国は政府観光局・寺院公式史料・史跡管理者・UNESCO等の歴史文化資料を追加して承認しました。日本・英国の国紹介写真は、クイズと同一の写真を再利用しないよう校正済みです。過去の写真・文章を自動的に出典確認済みと認定しません。
- 編集するのは `country-content.json` です。`python country_content.py --sync` が既存の4ファイルへ書き出します。`python country_content.py --check` は編集せず不整合を検出します。
- `build_site.py` と GitHub Actions で出力の食い違いを拒否します。196国の地理索引と、実際に公開可能な承認済み国は異なります。 名称の解決と写真の国籍判定は共通の `country-catalog.json` を参照し、国コードごとにPythonへ固定の国名を追記する運用は廃止しました。
- 小旅行の歴史・文化を裏付ける出典がまだない文章は、今後の内容監査で補強する対象です。写真のCCライセンスだけでは文章の史実確認の代わりになりません。

## 編集コンセプトと改善ロードマップ（2026-11-16）

**世界の失敗が、あなたの夜を少し軽くする。** 世界の実際の失敗や計画の誤算を、疲れた読者が夜9時に安心して読める短い日本語で伝える。事実と「AIのひと言」の創作を明確に分離し、当事者や被害者を嘲笑しない。

- **最優先：記事品質** — すべての主張を独立した出典で検証し、記事の詳細まで自然な日本語で提供する。確認できないニュースは公開しない。誤りが判明した場合は訂正・更新履歴を残す。現行の英語詳細文と既存記事の真偽は別途点検が必要。
- **編集の幅** — 重大な判断ミスをした個人・職人・従業員・選手を最優先。国・地域や題材の幅は、同程度に優れた確認済み候補の間で調整する。企業規模や分類の均等ノルマを理由に小さな珍事で埋めない。
- **AIのひと言** — 事実を捏造せず、判断や計画の意外性に温かいユーモアを添え、読者が自分の失敗を少し軽く感じられる表現を目指す。
- **今夜のひと言** — 新しい配信号の公開時、配信日と採用記事のジャンルに基づいて編集済みの日本語メッセージから自動選択し、公開JSONに保存する。読者画面と共有文面に反映する。現在は安全な定型文選択方式で、AIによる自由生成ではない。過去の公開号は既存の固定文を表示する。
- **世界地図・国別アーカイブ** — 今夜の記事の掲載国を示す地図と、国から過去記事を探せる導線を将来追加する。国名の正規化、地域バランス、スマートフォンでの操作性を検証してから公開する。

新機能の追加よりも、正確な日本語記事と信頼できる編集体制を優先する。

## 2026-11-20の編集フロー改善：重複したAI事実監査を縮小

信頼済み報道機関の実際の独自取材記事本文1本で掲載対象にできる。編集AIが記事化した内容と元記事の間で、数字・人物・日付・国・翻訳・法的段階・被害者への配慮に誤りが生じていないかだけを、**短い出典照合**で確認する。元記事をAIが独自に再取材する工程は行わない。原文を取得できない場合や断定の根拠がない場合は掲載せず、速報・SNS転載・プレスリリースのみでは承認しない。細かなAI採点条件を減らしつつ、事実性と安全上の拒否条件は残す。

日替わり偉人の名言を表示するようになったため、配信号の締め文生成と別AIによる再審査という未使用の2呼び出しを停止。通常号・月間特集の両方を出典照合中心に整理。旧号のデータは変更しない。

## 2026-11-20からの選定基準：大きな個人の大失敗

- **第一候補**：個人の重大な勘違い、誤判断、無謀な計画、取り違えなどによって、本人の予想と大きく食い違う結果が生じた実話。人物の知名度ではなく、判断の特異性と確認できる結果を重視する。
- **二段階の選定**：見出し中の人物と重大な結果は未確認候補の順位付けにのみ使用。元記事の本文と独立AI監査で「本人による失敗」と「大きな結果」がともに確認されたものだけを強く優先して先頭に配置する。
- **非採用**：小さな誤字・単純な手違いを主役に据えること、被害者の不幸を笑うこと、損害・動機・原因を創作すること。大きな個人ミスが確認できない日は本数を水増ししない。過去の公開号は変更しない。

## 世界の情報源拡張と稼働監視（2026年11月17日）

登録台帳 `data/news-source-registry.json` は、世界14市場（新聞・報道通信社・公共放送・科学・スポーツ・地域ニュース）の**追加RSS 68フィード、50媒体**を明示的に管理します。既存のBBC・NPR・各地の直接RSSも継続使用します。UPIの「Odd News」は、夜の読者向けの珍しいニュースを探すための優先収集先です。

- `news_sources.py` がRSS台帳を起動前に検証し、同じフィードの重複登録、HTTPリンク、予期しない媒体ドメインを拒否します。異なる媒体の元記事が必要なケースと、登録済み媒体の独自取材記事1本を確認できるケースを分けます。**RSSに登録されている事実だけでは記事採用されません。**

## 国紹介・小旅行の写真選定基準（v2）

国の紹介写真は「その国の写真である」だけでは採用しません。次の基準で編集審査します。

1. **一目で国を連想できること（最優先）**：主役はその国を象徴する建築物・自然景観・文化的ランドマーク。説明文がないと国を判別できない干潟・水面・空・道路などの接写は表紙に使わない。
2. **画面で美しく見えること**：主役が写真の中央付近で明瞭、十分な解像度、適切な露出・色・構図。スマートフォンで縦横にトリミングしても被写体が切れないこと。
3. **正確性と権利**：写真の国・場所を検証し、著作者・ライセンス・出典を記載する。無断転載や、別の国の写真への置き換えは禁止。
4. **重複防止**：同じ国・同じ名所・同じ画像が配信をまたいで過度に続かないよう履歴を確認する。ローテーションのために品質を犠牲にしない。
5. **フォールバック**：第一候補が読み込めない場合、同じ国の権利確認済みの写真を試す。写真がない場合は表示不能を明示し、無関係な写真で埋めない。

代表写真の優先順位は `index.html` の `TODAY_COUNTRY_PHOTO_RULES` で管理します。国を象徴する名所を100点、認知度の高い景観を80点程度、補足的な景色を60点未満とし、同じ国の候補間で高得点を先に表示します。点数は編集上の優先順位であり、画像の画質を自動判定するものではありません。画像そのものの目視審査も必要です。

政府観光局・国立公園局・UNESCO・ベティーズ・ホープ考古学資料で国紹介と史実を確認し、5枚の同国の異なる写真と各作者・CCライセンスを個別に照合しました。ネルソンズ・ドックヤードとデビルズ・ブリッジはそれぞれ独立した写真を使った読み物で、代表写真・2つのクイズ正解写真を重複させません。承認前の整備PR #114で519件の自動テスト、写真バンドル、公開サイト構築、320/375/393pxのスマートフォン画面検査が合格したため、`AG.status` を明示的に `approved` として記録します。

## 2026-11-21：ニュース掲載国とは別の「国を選んで旅する」

従来は、せっかく編集承認した世界の国紹介・写真クイズ・長めの小旅行が、その日のニュースに該当国が登場しないと読者に見つけられませんでした。新しい「ニュースがなくても、世界を旅する」では、地理索引の196件すべてを無条件に並べるのではなく、編集者が `approved` と明示した国だけを一覧表示します。どの国も、実写真・独立した文化史料・豊かな小旅行の２段落を、最新ニュースの公開件数とは関係なく読むことができます。ニュースの配信国ピンは**実際に掲載された国だけ**で、探索用リストの国数と混同しません。

表示される国のリストは `country-content.json` から `country_content.py --sync` で生成し、`--check` は未承認国の混入や承認リストの古さをエラーとして拒否します。独立した閲覧時の「この国のニュース」ボタンは出さず、クイズと小旅行へ進みます。画像の本人・ライセンス・観光地は元の写真データを利用し、ニュース・アーカイブの改変や有料AI APIの追加は一切しません。モバイル画面では、12か国の一覧を閉じておけるため記事の邪魔をしません。

## 2026-11-21：写真付き3択クイズの公開前整合性を強化

公開承認済みの国のすべての2問について、正解番号が0〜2の**整数**であること、3つの選択肢が互いに異なること、問題・正解の解説・写真ラベル・ツッコミに十分な本文があることを検査します。クイズ写真の出典・著作者・ライセンスと国名を照合し、**異なる写真IDが同じ画像を示す**場合や、国の表紙と正解画像を再利用する場合も拒否します。未承認国では不備を編集キューへ表示し、機械的に国を承認することはありません。

この形式検査は正解の歴史的・地理的**事実確認に代わるものではなく**、国別の史料確認と権利審査は継続します。写真生成・追加AI呼び出し・ニュース記事の改変・スタンプ帳の復活はありません。
