# よる9じの世界便り

> 個人も、会社員も、企業も。ニュースは実話、ツッコミ担当はAI。うまくいかない日の、世界の大失敗５連発。

**公開サイト**: https://ogasawaratouei1998-lgtm.github.io/yoru9-world-letter/

世界の実話の大失敗と、事実から区別したAIの創作ツッコミを5本ずつ届けるための、無料・非営利のWebサイトです。ニュースの内容や当事者の被害を無視して笑いものにすることは避けます。

## 2026-11-10 現在の稼働状況

- **公開中**: 過去のニュース5本を使った創刊準備号（読者画面、AIのひと言、出典、アーカイブ画面）。
- **実装済み**: GitHub Actionsからの読者サイトデプロイと公開安全テスト。
- **収集動作を確認済み**: Google News RSSを利用し、2026-11-10に未確認のニュース候補75件を取得・成果物へ保存。毎日16:37（日本時間）の収集を予約（GDELTはアクセス制限を受けたため代替手段を追加）。
- **公開予約を実装済み**: 21:07（日本時間）に承認済み5本だけを公開。承認のない日は更新を行わず、定時公開の実運用は未検証。
- **未完了**: 毎日のニュース5本の事実確認・承認・AIツッコミ作成の継続運用、プッシュ通知。承認済み5本がなければ配信号は更新されません。
- **重要**: 21:07はGitHub Actionsの起動予定です。ネットワークや混雑により配信時刻がずれる可能性があります。

## ファイルと仕組み

- `index.html`: 読者向けサイト。ニュースとAIの創作を分けて表示。
- `editor.html`: 編集者向けローカルHTML。ニュース候補を読み込み、出典を確認し、承認済みJSONを出力。
- `collect_candidates.py`: GDELTの見出しを収集。未確認情報は自動公開しません。
- `publish_approved.py`: 日本時間21時以降、**人が明示的に承認した5本だけ**を公開用JSONと過去号に反映。
- `build_site.py`: 公開に必要なファイルだけをサイトに梱包。未確認候補・承認記録・編集プログラムは公開サイトの配布物に含めません。
- `data/current.json`, `data/archive/`: 読者へ公開する号と過去号。
- `data/approved/`: 人が確認・承認した記事の置き場所。**GitHubリポジトリ自体は公開**のため秘密情報は置かないでください。
- `.github/workflows/`: 収集、公開、安全テスト、GitHub Pagesデプロイ。

運用方法・GitHub Pagesの設定上の注意は **[OPERATIONS.md](OPERATIONS.md)** を参照してください。

**現段階では毎晩新しいニュース5本が自動生成されているわけではありません。** 未確認の情報を誤って配信しないことを優先しています。
