# よる9じの世界便り

> 個人も、会社員も、企業も。ニュースは実話、ツッコミ担当はAI。うまくいかない日の、世界の大失敗５連発。

**公開サイト**: https://ogasawaratouei1998-lgtm.github.io/yoru9-world-letter/

世界の実話の大失敗と、事実から区別したAIの創作ツッコミを5本ずつ届けるための、無料・非営利のWebサイトです。ニュースの内容や当事者の被害を無視して笑いものにすることは避けます。

## 2026年11月11日現在の状態

- **公開中**: 過去の実話5本を使った創刊準備号（今夜の正式号公開まで）。
- **初回の承認済み5本**: [2026-11-11 創刊特集号](data/approved/2026-11-11.json)。**当日に発生したニュースではなく、過去の実話を集めた特集です**。今夜21時台に予約公開します。
- **読者画面**: 5本すべてにAIのひと言と報道日を表示。創刊特集号・今夜の配信号・前回号を区別し、オフライン時は保存済みであることを明示。
- **ニュース候補収集**: Google News RSSの日本を含む10地域の検索を実装。2026年11月11日朝のテストで**未確認候補75件を取得**。毎日16時37分ごろの予約を設定。
- **安全な公開処理**: 通常号は過去7日以内の報道、古い話題は特集号と理由を明示。人の確認が完了した5本がなければ新しい公開号は作成しません。
- **夜間公開**: 21時07分を初回として23時台まで複数回の予約。GitHub Actionsの遅延・実行漏れへの備えです。22時27分と23時27分には独立した公開状態チェックも起動予定です。
- **動作確認**: 自動テストはGitHub Actionsで実行。実際の初回定時公開はまだ検証中です。
- **未実装**: ニュースの自動的な事実認定・5本のAI自動編集、読者向けのプッシュ通知。

## 主なファイル

- `index.html`：読者用サイト（配信日・報道日・AIのツッコミ・アーカイブ）。
- `service-worker.js`：読者画面と**既に公開済みの号のみ**を保存するオフライン対応。
- `editor.html`：編集者向けローカルHTML。未確認の記事を選び、記事の確認と人の承認を行う。
- `collect_candidates.py`：10地域のニュース候補を収集。取得しただけでは掲載されません。
- `publish_approved.py`：夜21時以降、承認済み5本のみを公開します。
- `check_release_health.py`：公開済みデータの欠落を検知する。
- `build_site.py`：読者用のファイルのみをGitHub Pagesに配布。
- `data/current.json`, `data/archive/`：公開中の号と過去号。
- `data/approved/`：人の承認済み記事。**リポジトリPublicにつき閲覧可能**であり、機密情報を置けません。

詳しい運用手順は **[OPERATIONS.md](OPERATIONS.md)** を参照してください。

**このアプリのニュースの真偽を機械が自動保証するわけではありません。** ニュースが取れなかった日は無理に更新せず、古い号を新しい号として見せないことを優先しています。
