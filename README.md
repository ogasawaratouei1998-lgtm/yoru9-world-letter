# よる9じの世界便り

> 今日も一日、おつかれさま。ニュースは実話、ツッコミ担当はAI。世界の「まさか」を、今夜も。

**公開サイト**: https://ogasawaratouei1998-lgtm.github.io/yoru9-world-letter/

世界の実話の大失敗と、事実から区別したAIの創作ツッコミを1〜3本届けるための、無料・非営利のWebサイトです。ニュースの内容や当事者の被害を無視して笑いものにすることは避けます。

## 主なファイル

- `index.html`：読者用サイト（配信日・報道日・AIのツッコミ・アーカイブ）。
- `service-worker.js`：読者画面と**既に公開済みの号のみ**を保存するオフライン対応。
- `editor.html`：編集者向けローカルHTML。未確認の記事を選び、記事の確認と人の承認を行う。
- `collect_candidates.py`：10地域のニュース候補を収集。取得しただけでは掲載されません。
- `publish_approved.py`：夜21時以降、承認済み1〜3本を公開します。
- `check_release_health.py`：公開済みデータの欠落を検知する。
- `build_site.py`：読者用のファイルのみをGitHub Pagesに配布。
- `data/current.json`, `data/archive/`：公開中の号と過去号。
- `data/approved/`：人の承認済み記事。**リポジトリPublicにつき閲覧可能**であり、機密情報を置けません。

詳しい運用手順は **[OPERATIONS.md](OPERATIONS.md)**、通知とAI編集支援の手順は **[NOTIFICATIONS_AND_EDITORIAL.md](NOTIFICATIONS_AND_EDITORIAL.md)** を参照してください。

**このアプリのニュースの真偽を機械が自動保証するわけではありません。** ニュースが取れなかった日は無理に更新せず、古い号を新しい号として見せないことを優先しています。

## 編集コンセプトと改善ロードマップ（2026-11-16）

**世界の失敗が、あなたの夜を少し軽くする。** 世界の実際の失敗や計画の誤算を、疲れた読者が夜9時に安心して読める短い日本語で伝える。事実と「AIのひと言」の創作を明確に分離し、当事者や被害者を嘲笑しない。

- **最優先：記事品質** — すべての主張を独立した出典で検証し、記事の詳細まで自然な日本語で提供する。確認できないニュースは公開しない。誤りが判明した場合は訂正・更新履歴を残す。現行の英語詳細文と既存記事の真偽は別途点検が必要。
- **編集の幅** — 職場・会社員、個人、企業・組織の3分類を可能な限り均等に扱い、国・地域も分散させる。国別・分類別のノルマを満たすために証拠の基準を下げない。複数日を通じた地域の偏りの自動抑制は今後の課題。
- **AIのひと言** — 事実を捏造せず、判断や計画の意外性に温かいユーモアを添え、読者が自分の失敗を少し軽く感じられる表現を目指す。
- **今夜のひと言** — 新しい配信号の公開時、配信日と採用記事のジャンルに基づいて編集済みの日本語メッセージから自動選択し、公開JSONに保存する。読者画面と共有文面に反映する。現在は安全な定型文選択方式で、AIによる自由生成ではない。過去の公開号は既存の固定文を表示する。
- **世界地図・国別アーカイブ** — 今夜の記事の掲載国を示す地図と、国から過去記事を探せる導線を将来追加する。国名の正規化、地域バランス、スマートフォンでの操作性を検証してから公開する。

新機能の追加よりも、正確な日本語記事と信頼できる編集体制を優先する。


## 夜の編集・体験の原則

[編集・体験の約束](EDITORIAL_PROMISE.md)に、読者が読了・笑い・再訪を強いられない設計と、
温かい実話の選定、過度な励ましや苦しみの比較を避ける編集方針を記載しています。
記事の真偽や安全性、軽いユーモアを優先し、表示回数や記事数のために基準を下げません。

## 直近30日の独立ニュース発掘（2026-11-17）

`monthly_research.py` と `.github/workflows/monthly-editorial.yml` は、通常の夜9時配信とは独立して直近30日のニュース候補を毎日14:15（JST）に探索します。RSS/GDELT/Bingから得た見出しは**発掘候補であり、公開済みの事実ではありません**。

異なる2媒体の元記事があれば、その独立性を確認して優先します。別媒体の追認がない場合も、**事前登録した信頼できる報道機関の独自取材記事1本**を取得できれば審査対象とします。SNS投稿の引用や転載だけの記事を単独根拠として採用しません。AI編集者と別段階のAI監査者が元記事本文、取材の独自性、出来事、報道日、地名、意外性、危害の有無を厳格に審査します。プログラム側もURL・登録媒体・取得本文・日付・重複・本文長・安全性を確認します。1媒体のみの収録記事には独立した追認がない旨を表示します。条件を満たす記事がなければ**何も追加せず、既存の公開記事を保持します**。公開された月間記事は `data/monthly/YYYY-MM-DD.json` に初回収録日で保存し、`data/monthly/index.json` に記録します。過去の日付に架空の「配信号」を作りません。

サイトは直近30暦日の収録データだけを表示し、過去の記録ファイルは監査のためGitに保持します。自動処理は成功したリリースのみGitHub Pagesに反映し、**GitHub Actionsの通常のpushでは連鎖デプロイされないため、同ワークフロー内で公開します**。再実行時も日別ファイルを書き換えません。Google Gemini APIキーがない場合、審査・公開を実行しません。人手で確認したニュースの真偽を保証するものではありません。
